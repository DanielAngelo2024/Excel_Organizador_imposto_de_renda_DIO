# 📊 Controle de Imposto de Renda em Excel

Projeto desenvolvido como **desafio prático do Bootcamp Santander – Excel com Inteligência Artificial – 2º Semestre**, com o objetivo de aplicar conceitos de organização de dados, usabilidade e automação em planilhas voltadas ao **controle de informações para declaração do Imposto de Renda**.

O projeto foi construído inteiramente no **Microsoft Excel**, priorizando uma **interface amigável**, visual moderno e navegação intuitiva, semelhante à experiência de um aplicativo.

---

## 🎯 Objetivo do Projeto

Facilitar a organização e o controle das principais informações necessárias para a declaração do Imposto de Renda Pessoa Física (IRPF), centralizando dados do titular, informes bancários e notas em um único arquivo estruturado.

---

## 🧩 Estrutura do Projeto

O arquivo é composto por **3 planilhas principais**, integradas por um **menu de navegação**, proporcionando uma experiência fluida ao usuário:

### 🧑‍💼 Titular
Planilha destinada ao cadastro dos dados do contribuinte, como:
- Informações pessoais
- Dados básicos necessários para identificação na declaração
- Organização clara e padronizada dos campos

### 🏦 Informes de Bancos
Área dedicada ao registro de:
- Informes de rendimentos bancários
- Saldos e rendimentos

### 🧾 Notas Bancárias e Holerites
Planilha voltada para o registro e organização de:
- Notas bancárias e comprovantes financeiros
- Extratos de holerites e rendimentos salariais
- Informações auxiliares para conferência de valores declarados
- Apoio ao controle e validação dos dados utilizados no Imposto de Renda

---

## 🧭 Interface e Usabilidade

- Interface visual inspirada em aplicativos  
- Menu de navegação para acesso rápido às planilhas  
- Layout limpo, organizado e intuitivo  
- Foco em usabilidade e experiência do usuário (UX)

> Este projeto tem caráter **educacional** e visa auxiliar na organização das informações. Ele **não substitui** a orientação de um contador ou profissional especializado para a entrega oficial da declaração do Imposto de Renda.
